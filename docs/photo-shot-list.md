# 撮影リスト（写真）

このデザインは写真が主役です。**院内・スタッフ・外観は必ず実際の写真**を使います（ストック写真を当院として見せない）。
スマートフォンで十分です。明るい時間に、窓からの自然光で撮ると雰囲気に合います。

## 優先度 高

| ファイル名 | 内容 | 使う場所 |
|---|---|---|
| `clinic-exterior.jpg` | 建物の外観と入口（看板が見えるように） | Access、Home |
| `clinic-entrance-from-street.jpg` | 駅側から歩いてきたときに見える景色 | Access（道順） |
| `parking-opposite.jpg` | 向かいの駐車場（オレンジの看板） | Access |
| `treatment-room.jpg` | 個室の診療室（3室のうち1つ、ドアが分かるように） | Home の強み、Treatments |
| `reception.jpg` | 受付・待合 | Home、About |
| `ct-xray.jpg` | CT・デジタルX線の機械 | Treatments |
| `team.jpg` | スタッフ全員の集合写真 | About、Home |
| `dr-kaneshima-chairside.jpg` | 院長が患者と話している様子（患者は後ろ姿など同意を得て） | About |

## あると良い

- `itero-scan.jpg` Invisalign の 3D スキャン画面
- `kids-corner.jpg` 子ども向けのもの（あれば）
- 駅（Sōbudai-mae）の出口、Camp Zama Gate 4 からの道順の写真

## 撮り方・形式

- 横向き、長辺 2000px 以上、JPG
- 人物が写る場合は本人の同意を得る（患者は原則写さない）
- 撮ったら `images/` に上のファイル名で入れ、Claude に「写真を入れて」と依頼する。Claude が圧縮・トリミングして配置する

## ストック写真を使ってよい場面

ブログ記事のイメージ（歯ブラシ、笑顔の家族など）に限り、Unsplash / Pexels など商用利用可のサイトの写真を使ってよい。
その場合も、院内やスタッフに見えるような写真は避ける。
