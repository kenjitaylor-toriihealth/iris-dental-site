# 月次データの置き場所

毎月1〜5日に、前月分のデータを `YYYY-MM/` フォルダ（例: `2026-12/`）に保存します。
このフォルダの中身は Git に入れません（.gitignore 済み）。数字は Claude が月次レポートにまとめます。

## 取り出すもの

| ファイル名 | 取り出し方 |
|---|---|
| `ga4-traffic-acquisition.csv` | GA4 → レポート → 集客 → トラフィック獲得 → 期間を前月に → 右上の共有 → ファイルをダウンロード（CSV） |
| `ga4-events.csv` | GA4 → レポート → エンゲージメント → イベント → 同上 |
| `ga4-landing-pages.csv` | GA4 → レポート → エンゲージメント → ランディング ページ → 同上 |
| `ga4-book-click-by-location.csv` | GA4 → 探索 → 自由形式（ディメンション: イベント名, link_location ／ 指標: イベント数、フィルタ: イベント名 = book_click）→ エクスポート |
| `search-console.zip` | Search Console → 検索パフォーマンス → 期間を前月に → エクスポート |
| `gbp.md` | Google ビジネスプロフィール → パフォーマンス の数字（閲覧数、ウェブサイトクリック、ルート、通話、口コミ件数・評価）をメモ |
| `intakeq.md` | IntakeQ の予約数（新患／再来、治療メニュー別が分かれば内訳も）をメモ |

全部そろっていなくても大丈夫です。あるものだけでレポートを作ります。
